# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

seqCNA calls copy number changes from sequencing data (shallow WGS or
targeted/exome) by comparing tumor BAMs to normal BAMs. It uses
`seqDNAcopy`, a fork of V. Seshan's package with mouse support added.
Steps: binned read counts, GC correction, CBS segmentation, segment
clustering, FDR-based significance, gene-level calls. `METHODS.md` has
the method text used in reports; `docs/seqCNA-vs-FACETS*.md` explains
when to use this instead of FACETS.

The code is bash and R scripts for an HPC cluster. There is no build
step, test suite, or linter. `ATTIC/` holds retired scripts.

## Running

The pipeline runs from a project directory with this repo checked out
as `seqCNA/` inside it. All outputs go to the current directory.

Required inputs in the project directory:
- `pipeline/` containing a subdirectory matching `alignments|bam` with
  the BAMs
- `tumors`, `normals`: one pattern per line, matched with `fgrep -f`
  against BAM paths
- `samples` is generated by PIPE.sh if absent

```bash
seqCNA/PIPE.sh TARGETTED   # BINSIZE=100 (IMPACT, exome)
seqCNA/PIPE.sh sWGS        # BINSIZE=auto
```

Single steps can be run by hand. Any wrapped tool run with no arguments
prints `docs/<name>.doc`.

```bash
seqCNA/getPairedCounts GENOME=hg19 TUMOR=t.bam NORMAL=n.bam ODIR=out/x SAMPLEID=s_T__s_N
seqCNA/seqSegment COUNTS=out/x/s_T__s_N_Counts.rda ODIR=out/x BINSIZE=100
seqCNA/selectBestMatch out
seqCNA/postProcess.sh <Assay> [Proj_XXXXX]
```

Valid `<Assay>` values are the directory names under
`resources/geneAnnotations/` (excluding `src`). PIPE.sh chooses the
assay from the genome only (b37/hg19 -> Exome, mm10/GRC_m38 ->
Mouse-Twist); other assays (IMPACT410, IMPACT505, M-IMPACT_v*) require
running postProcess.sh directly.

## Pipeline flow (PIPE.sh)

1. `fixChromosomeNames.sh` per BAM (bsub, logs in `LSF.FIX/`). Writes
   `bamRelabel/<base>/<base>__relabel.bam` with `chr` stripped from
   contig names. b37 BAMs are symlinked with their index instead.
2. `seqCNA.sh BINSIZE normal tumor` for every tumor x normal
   combination. Submits `getPairedCounts`, then `seqSegment` dependent
   on it via `-w post_done(...)`. Job names start with `$QTAG`; logs in
   `LSF/`.
3. `bSync` waits for jobs; `parseLSF.py` checks for failures.
4. `selectBestMatch out`: for each tumor, keeps the normal with the
   lowest `rms.logr` and writes `bestMatches____out`. PIPE.sh hard-links
   `out/` to `outAll/`, then deletes the non-best pair directories from
   `out/`.
5. `postProcess.sh <Assay> <ProjNo>`: copies PNGs to `<ProjNo>/`,
   concatenates the `.seg` files into `<ProjNo>___IGV.seg`, runs
   `fixXChrom.R` (renames the highest numeric chromosome to X), then
   `getGeneCalls` (writes `GeneMatrix.csv`, `SegmentMatrix.csv`,
   `<ProjNo>___GeneTable.xlsx`).
6. ImageMagick `convert` merges the PNGs into `<ProjNo>___seqSeg.pdf`.

After the pipeline:
- `delivery.sh /path/Proj_X/r_00N` copies deliverables into `seqcna/`
  there. `DELIVERY.md` and `DELIVERY_ZIP.md` are the email templates.
- `redactNormals.R` removes `__<normal>` from sample IDs in the four
  deliverable tables, rewriting them in place. Run it from a directory
  that contains exactly one copy of each.
- `Rscript plotSeg.R [-r] SEG.rda` re-plots a `_seqSeg.rda`; `-r`
  removes the normal ID from the title.

## Architecture

### Wrapper pattern

`getPairedCounts`, `seqSegment`, `getGeneCalls`, and `selectBestMatch`
are symlinks to `execWrapper.sh`. The wrapper exports `SDIR` (repo
directory) and `SNAME` (invoked name), prepends `$SDIR/Rlib` to
`R_LIBS`, and runs `Rscript --vanilla $0.R "$@"`. To add a tool: write
`foo.R`, symlink `foo -> execWrapper.sh`, add `docs/foo.doc`.

- `--vanilla` skips `~/.Rprofile`, so wrapped scripts cannot use its
  helpers. `include/tools.R` redefines `cc()` and `len()`.
- Wrapped scripts source `include/*.R` via `Sys.getenv("SDIR")`, which
  falls back to the relative path `seqCNA`.
- Standalone scripts (`plotSeg.R`, `redactNormals.R`, `fixXChrom.R`)
  run with plain `Rscript`. `redactNormals.R` calls `write_xlsx()` from
  `~/.Rprofile`, so it must not run with `--vanilla`.

### Argument parsing

Wrapped scripts take `KEY=VALUE` arguments parsed by
`include/parseArgs.R`. Keys are uppercased. Values are coerced to the
class of the default. A `NULL` default marks a required argument; if
one is missing, `parseArgs` returns NULL and the script prints its doc
file.

### R versions and seqDNAcopy

- `seqDNAcopy/` is a git submodule with the fork's source
  (`git submodule update --init`). `Rlib/seqDNAcopy/` is a committed
  compiled install, built with R 3.5.1. Rebuild from `Rlib/`:
  `R CMD INSTALL -l . ../seqDNAcopy`.
- PIPE.sh removes R from `PATH` and loads R 3.6.1 for counting,
  segmentation, and selectBestMatch. postProcess.sh loads R 4.2.2 for
  `fixXChrom.R` and `getGeneCalls`.
- Scripts that run under R 3.x cannot use the native pipe `|>`
  (requires R >= 4.1).

### Genome handling

`GenomeData/getGenomeBuildBAM.sh` identifies the reference by the md5
of the sorted `@SQ` header lines (first 3 columns). The resulting tag
is mapped in two other places that must stay consistent with it:
- `seqCNA.sh`: tag -> `hg19` or `mm10` (the `GENOME=` argument)
- `PIPE.sh`: tag -> annotation assay (Exome or Mouse-Twist)

`seqCNA.sh` runs on the relabeled BAMs, so it sees the md5 after `chr`
stripping (e.g. UCSC mm10 becomes `mm10-relabel`). `getGeneCalls.R`
maps hg19 to b37 (`normalizeGenomeTag`) when choosing
`resources/geneAnnotations/<ASSAY>/<genome>/gene_annotations.txt.gz`.
Chromosome X is numeric in segment output (23 human, 20 mouse).

### Sample ID conventions

`getSampleTag.sh` reads `SM:` from the BAM `@RG` lines and adds an `s_`
prefix if missing. A pair ID is `<tumor>__<normal>`. Several scripts
parse this format with regexes: `selectBestMatch.R` (`__s_`),
`getGeneCalls.R` (sample columns match `^s_`), `redactNormals.R`
(`__.*`), `plotSeg.R` (`__s_.*$`). Changing the naming breaks them.

### Per-pair outputs

`out/<first 2 chars of tumor ID>/<tumorId>/<pairId>/` contains:
- `<pairId>_Counts.rda` and `.json` (getPairedCounts)
- `<pairId>_seqSeg.rda` (DNAcopy object named `out`), `.seg`, `.png`,
  `.out` (seqSegment)

`seqsegment()` returns positions in Mb; seqSegment.R multiplies by 1e6
before writing `.seg`. The `.out` file is `key = value` QC metrics.
`parseSeqCNAOutFile()` in `include/tools.R` reads it and treats a file
without `X.seg.mean.avg` as incomplete. selectBestMatch uses it to rank
normals; getGeneCalls uses it to get the genome. Outputs record
`VERSION` and the repo's `git describe` (suffix `-UNCOMMITED` if the
tree is dirty).

### Calling parameters

- seqSegment.R: `MINBINCOUNT=35`, `undo.SD=2`, cluster merge threshold
  0.04 (`include/clusterSegs.R`, adapted from FACETS). The cluster with
  the smallest `abs(logR)/sqrt(nProbes)` is set to logR 0.
- getGeneCalls.R: significant if `FDR < 0.05` and `|seg.mean| > 1`.
  When a gene overlaps several segments, the lowest `seg.mean` is used,
  so deletions take priority over amplifications.
- `METHODS.md` states these values; update it if they change.

## Hard-coded environment dependencies

The scripts were written for the older MSKCC LSF clusters (CentOS 6/7).
These references do not resolve on the current RHEL 8 / Slurm host:

- `PIPE.sh`: `module load R/R-3.6.1`, `R_LIBS=/home/socci/lib/R/...`
- `postProcess.sh`: `module load R/R-4.2.2`, same `R_LIBS` path
- `execWrapper.sh`: exits unless `/etc/system-release` reports major
  version 6 or 7
- `GenomeData/getGenomeBuildBAM.sh`: `SAMTOOLS=/opt/common/CentOS_7/...`
- `getGeneCalls.R`: Exome isoform override files under
  `/opt/common/CentOS_6-dev/vcf2maf/`
- `fixChromosomeNames.sh`: `module load samtools/1.19.2`; also calls
  `getGenomeBuildBAM.sh` from `PATH`, not `$SDIR/GenomeData/`
- LSF helpers `bSync` and `parseLSF.py`; `bsub -w post_done(...)` job
  dependencies
- `testR`: R 3.3.1 path under `/opt/common`

State of the current host as of 2026-10-19: `~/bin/bsub` is SchedMD's
LSF-to-Slurm wrapper script; available modules include `r/3.6.3`,
`r/4.4.1`, `R/4.3.0`, `samtools/1.20`; `bSync`, `parseLSF.py`,
`samtools`, and `convert` are not on `PATH`.
